
# Daily Expense Tracker

## Project Description
Daily Expense Tracker is a simple web-based application developed using PHP and MySQL.

It helps users record, view, and manage their daily expenses.

## Technologies Used
- HTML
- CSS
- PHP
- MySQL
- XAMPP

## Features
- Add daily expenses
- View all expenses
- Delete expenses
- Calculate total expenses
- Monthly Expense Summary
- Search Expense
- Category-wise Expense Summary
